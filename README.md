## Deploy to GitHub Pages

1. Create a GitHub repository named `portfolio` under the GitHub account:
   `madhusreemanokaran-a11y`
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

The expected shareable URL will be:

`https://madhusreemanokaran-a11y.github.io/portfolio/`

If you choose a different repository name, the GitHub Pages URL will change accordingly.

## Easy updates

- Personal details: edit the relevant text in `index.html`.
- Skills: edit the skill cards in `index.html`.
- Projects: add another project card following the existing project-card structure.
- Certificates: duplicate a certificate card and change its image/title/details.
- Resume: replace `assets/resume/resume.pdf` with the new file while keeping the same filename.
- Profile photo: replace `assets/images/profile.jpg` with the new image while keeping the same filename.
- Theme/colors: edit the CSS variables at the top of `css/style.css`.
- Interactions: edit `js/script.js`.
